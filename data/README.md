# Benchmark data

This directory contains the exact data references used for the 3D-Fit paper:

- `test_sets/` contains the clustered CrossDocked and PLINDER test parquets,
  including the pre-sampled generation conditions.
- `novelty_reference/` contains the canonical SMILES sets used to calculate
  novelty for CrossDocked and PLINDER results.

The library and repository scripts use these files by default.
