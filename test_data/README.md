# Complete Test Data Snapshot for 3D-fit Benchmark

Generated using the script `scripts/add_prompts_for_hf_dataset.py`
The dataset in this directory contains both crossdocked and plinder, with the sampled
conditions we used for our experiments and also the prompts added to the dataset. Adding
the prompts in this way is not intended to be part of the usual pipeline of using the
benchmark, the idea being to sample and use them for generation and then for scoring. 
This was used to create the dataset for sharing on Hugging Face, it is included here for
the review period.
